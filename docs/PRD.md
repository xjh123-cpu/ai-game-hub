## 1. 项目背景

AI 原生应用正在快速普及。随着大模型 API（如智谱 GLM、DeepSeek 等）的成熟与降价，个人开发者已能低成本地构建具备「智能生成内容」能力的交互式应用。游戏是验证大模型能力最直观的场景之一——大模型可以实时生成剧情、智能出题、公正裁判，从而让游戏内容「永不重复」。

本项目以「AI 互动小游戏」为选题，基于智谱 GLM（OpenAI 兼容接口），综合运用前四个实验所学（API 调用、提示词工程、JSON 结构化输出、图形界面开发），构建一个端到端的 AI 游戏应用，并完成从需求分析到部署展示的完整工程链路。

## 2. 目标用户

| 用户 | 特征 | 核心诉求 |
|------|------|---------|
| 在校学生 | 喜欢轻松互动、时间碎片化 | 课间快速玩一局、无需下载、打开即玩 |
| 教师/演示者 | 需要展示大模型应用能力 | 直观看到 AI 生成剧情/出题/裁判的全过程 |
| 普通网民 | 对 AI 好奇、愿意尝鲜 | 体验「AI 当游戏主持人」的新鲜感 |

## 3. 核心场景（解决什么问题）

1. **场景 A**：用户想玩文字冒险游戏，但传统游戏剧情固定、玩一遍就腻。→ 由大模型实时生成剧情，每一局的剧情都不同。
2. **场景 B**：用户想玩猜谜游戏，但题库有限、很快刷完。→ 由大模型围绕任意主题即时出题，题库「无限」。
3. **场景 C**：开发者想学习如何把大模型 API 集成到交互式应用中。→ 本项目提供清晰的模块化工程示例（llm.py / prompts.py / games / app.py）。

## 4. 功能清单

### 4.1 Must have（必须实现）

| 编号 | 功能 | 说明 |
|------|------|------|
| F1 | AI 文字冒险 | 大模型实时生成剧情（100 字内）、每轮 3 个分支选项、游戏结束判定、多轮上下文记忆 |
| F2 | AI 猜谜闯关 | 支持选择主题与难度、AI 出题、AI 裁判判定、积分统计、积分兑换提示 |
| F3 | 双形态图形界面 | ① **云端网页版**（Streamlit，`app.py`）：公开链接打开即玩，是实验要求的公开交付形态；② **桌面版**（pywebview + HTML/CSS/JS，`main.py`）：原生窗口，可打包 exe 离线运行。两者共用同一套 `games/` 业务逻辑 |
| F4 | 密钥安全管理 | API Key 从「环境变量 + 本地 config.json」双通道读取，首次启动弹窗设置，`.gitignore` 排除 |
| F5 | 异常处理与重试 | 大模型调用内置指数退避重试（最多 3 次）、统一异常处理 |
| F6 | 结构化输出校验 | 对模型返回的 JSON 做字段校验，缺失/误用字段时自动兜底或重新生成 |
| F7 | 存档与读档 | 文字冒险支持本地存档/读档（多槽位），游戏进度可延续 |
| F8 | 连击与排行榜 | 猜谜连续答对连击加分，最高分本地持久化 |

## 6. 提示词模板库设计

提示词与代码分离，集中在 `prompts.py` 中管理，支持参数插值，便于 A/B 测试：

| 模板 | 用途 | 关键设计点 | 温度策略 |
|------|------|-----------|---------|
| `ADVENTURE_SYSTEM_PROMPT` | 文字冒险 GM 角色设定 | 明确身份、100 字限制、3 选项、JSON 格式、game_over 条件、反注入防护 | 0.9（高温，剧情多样） |
| `QUIZ_PROMPT` | AI 出题 | 主题/难度插值、明确返回字段、谜底防重复、**禁止谜面或提示中出现谜底字词** | 1.0（高温，题目多样） |
| `QUIZ_FACT_CHECK_PROMPT` | 出题事实核查 | 核实谜面描述是否符合常识，拦截模型编造的史实 | 0.0（低温，核查稳定） |
| `JUDGE_PROMPT` | AI 裁判 | 允许同义/别称、给出判定标准、明确拒绝「不知道」类作答 | 0.0（低温，判定稳定） |
| `LLM_JUDGE_PROMPT` | 评估裁判（LLM-as-Judge） | 三维度 1~5 分、要求 JSON 输出 | 0.0（低温，评分稳定） |

## 8. 关键风险与对策

| 风险 | 对策 |
|------|------|
| 模型偶发返回非法 JSON | `parse_json` 兜底提取、`_validate_state` 字段校验、失败触发重新生成 |
| API 限流/网络波动 | `llm.py` 指数退避重试（1s→2s→4s） |
| 密钥泄露 | 本地走环境变量 / `config.json`，云端走平台 Secrets；`.env`、`.streamlit/secrets.toml` 均被 `.gitignore` 排除 |
| 恶意提示词注入 | system 提示词内置反注入规则 + 输出状态校验兜底 |
| 公开部署被刷量 | 网页版 `app.py` 内置会话级限流：相邻调用 ≥2 秒、每分钟 ≤10 次、单会话累计 ≤200 次 |
| 超长输入灌水烧 token | 所有用户输入先经 `games/clamp_text` 截断（行动 ≤500 字、主题 ≤30 字、作答 ≤200 字）再交给模型，界面同步提示 |
| 错误信息误导排查 | `llm.py` 区分可重试 / 不可重试异常：不可重试（如密钥无效）立即中断并翻译为可操作提示，不再误报「已重试 N 次」 |
